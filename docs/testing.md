# ポトロクエスト動作確認

ゲームを変更した後は、GitHub Pagesへ反映する前に次の検査を実行します。

```powershell
npm install
npm test
```

## 検査内容

- 全JavaScriptの構文
- `index.html`から参照されるスクリプトと画像・音声の存在
- 通常版エンディングが有効で、七夕版が無効であること
- タイトルとあらすじの表示
- 推し名を入力した冒険開始
- 町のキーボード・十字キー移動、建物の衝突、会話中の移動禁止
- メイド喫茶の購入、即時所持数・コイン更新、コイン不足・所持上限の購入拒否
- 休憩室のHP・TP全回復、状態異常・一時効果の解除
- 町と1F・2Fの往復時の探索状態保持、通常敵のコイン報酬とBOSS・たまちゃんの除外
- 新しい冒険開始時の町の座標・コイン初期化、町の320px・390px・1280px幅表示
- フィールドのキーボード・十字キー移動、川・外周・建物の衝突、橋の通行
- フィールド入口での入場・見送り、確認画面・装備画面での移動禁止
- 広場での任意の仲間加入・重複加入防止・冒険再開始時のリセット
- 仲間の1ラウンド1回行動、回復TP・HP上限・TP不足時の攻撃、防御と状態異常の分離
- 全敵特殊行動の仲間への対象指定と、主人公の装備補正・耐性が仲間へ漏れないこと
- 主人公が倒れた後の継続、仲間の攻撃による先手側ラウンド中の勝利、全滅時のゲームオーバー
- 仲間の成長・休憩室での蘇生と回復・作戦選択、2人のお給仕画面の320px・390px・1280px幅表示
- 町・フィールド・1F・2Fの往復、フィールドの描画ピクセルと320px・390px・1280px幅表示
- 1F・2Fの生成と宝箱数
- 宝箱で入手した装備の比較表示と即時装備
- 同じ通常敵が連続出現せず、階層移動時に履歴がリセットされること
- 階段・ボスが指定された3領域内に配置されること
- 初期装備の参照と通常ルーレットの確率境界
- 効果一覧への装備名・ランク・性能・新装備の自動反映と、おまじないの基本消費TP表示
- 効果一覧の文字が320px・390px・1280px幅で列からはみ出さないこと
- スピードトレイの開幕・以降のすばやさ、先手判定、2体出現時のターン計数、次のお給仕でのリセット
- 回復おまじない・回復道具の装備補正とHP上限、状態回復の当選境界と非装備・回復量0時の非発動
- 通常敵とのお給仕開始と通常攻撃
- 初回お給仕案内と、敵ごとの初遭遇ヒント
- 敵の特殊行動予兆と、次ターンの特殊行動発動
- バフ・デバフの同時表示と色分け
- 高防御時に適用される敵通常攻撃の最低ダメージ
- マップとお給仕中の、どうぐ・装備・おまじないメニュー

Windowsでは、インストール済みのChromeまたはEdgeを自動的に使用します。別のChromium系ブラウザを使う場合は、`PLAYWRIGHT_CHROMIUM_EXECUTABLE`に実行ファイルのパスを指定します。

スマートフォン幅の確認画像も保存する場合は、`POTORO_TEST_SCREENSHOT=1`を指定します。画像は`test-results`へ保存され、Gitの管理対象にはなりません。

この検査は主要導線の破損を早く見つけるためのものです。ランダム抽選の体感、難易度、スマートフォン固有の表示については、引き続き実機確認も行います。
