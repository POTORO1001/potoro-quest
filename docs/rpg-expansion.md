# RPG拡張

開発ブランチ: `codex/rpg-expansion`。公開版の `main` は変更しません。

## 第1段階

- マップの主人公をメイドさんの画像に変更。
- 1マス内に表示し、移動・イベント・お給仕のルールは維持。
- 画像未読込・読込失敗時はカチューシャとエプロンを描いた簡易表示を使用。

## 第2段階

- 冒険開始時に、歩いて移動するポ・トロの町を表示。
- お屋敷: 物語の案内と、郊外への出発。
- 休憩室: 無料でHP・TPを全回復し、状態異常・一時的な効果を解除。
- メイド喫茶: 既存のオムライス・ココア・ホットミルクを購入。
- 広場: 町のメイドさんと会話。
- 東の出口: 郊外へ出発。
- ダンジョンの「外へ出る」から郊外・町へ帰還でき、再入場時には同じ階・位置へ復帰。
- 探索位置、マップ、開けた宝箱、装備・所持品は同じ冒険中に保持。永続セーブは未実装。

試作用のお給仕コインは初期30枚、通常敵1人のお給仕で5枚。
BOSS・たまちゃんにはコイン報酬なし。喫茶の価格はオムライス10枚、ココア8枚、ホットミルク12枚。
既存のどうぐの所持上限を購入にも適用します。価格・報酬は今後のバランス調整対象です。

町は `js/town.js` が管理し、既存のマップ・装備・どうぐ定義の後で読み込みます。
町の座標は `state.town` に分離し、町の十字キーは `data-town-move` を使用。
隠れたダンジョンの移動入力を拒否し、町の移動で探索状態を変更しません。

## 第3段階

- 町とお屋敷をつなぐ「ポ・トロの郊外」を追加。
- 町の出口・お屋敷の案内から郊外へ出発し、西の町と東のお屋敷の間を歩いて移動。
- 川は橋のあるマスのみ通行可能。森の外周・樹木・建物には衝突判定を適用。
- 町・お屋敷の入口で、入場か「歩き続ける」かを選択可能。
- ダンジョンから外へ出るとお屋敷の入口に復帰。町から出ると町の入口に復帰。
- フィールドの移動は `state.field` に分離し、ダンジョン座標・探索情報・所持品を保持。
- 今段階ではフィールドのお給仕・新しい探索先・報酬は追加しません。

`js/field.js` は `js/town.js` の後で読み込み、既存のメイド画像・建物描画・入場ダイアログを使用。
フィールド入力は `data-field-move` と専用キーボード処理で管理し、確認画面・装備画面では移動を禁止します。
町と郊外のBGMは既存の1F音源を使用し、2Fから帰還して音を再度ONにしても2F音源に切り替えません。

## 第4段階

- 町の広場でメイドさん「こはる」（仮名）を誘い、2人パーティを結成。
- 加入は任意。加入前は従来の1人のお給仕を維持。
- 仲間のHP・TP・状態異常・防御を主人公と分離。
- 敵はHPの残るメンバーから対象をランダムに選択。連続攻撃は同じ対象に向かい、対象が倒れた場合は打ち切り。
- こはるは敵側の行動が終わった後に、1ラウンド1回自動行動。敵が2人いても行動回数は増えません。
- 作戦「攻撃」: 主人公の選択対象へ通常攻撃。倒れている対象は生存する敵へ切り替え。
- 作戦「回復優先」: TP3で、HP割合の低い生存メンバーを `10 + Lv*2` 回復。回復不要・TP不足なら攻撃。
- 作戦「守り」: 自分への通常攻撃等を次の敵ラウンド中に半減。主人公が倒れている場合は攻撃に切り替え。
- 主人公が倒れても仲間が残れば、専用の継続ボタンでお給仕を続行。全員HP0でゲームオーバー。
- 回復おまじないでは倒れたメンバーを蘇生しません。休憩室では2人ともHP・TP・状態を全回復。
- 仲間は主人公と同じレベルに成長。Lv1時はHP24、TP8、攻撃6、防御9。1レベルにつきHP+4、TP+2、攻撃+2、防御+1。
- 主人公のレベルアップ時は仲間も全回復。EXP・コイン・どうぐ報酬は敵パーティ1回分で、人数による増額なし。
- 仲間の装備変更・独自すばやさ・手動おまじない選択は今段階では追加しません。

`js/companion.js` を `js/ui.js` の前で読み込みます。仲間は `state.player.companion` に保持し、新しい冒険ではリセット。
主人公の装備補正・耐性・威力強化は仲間へ流用しません。
仲間表示は既存のメイド画像を元の肌色のまま使用し、町・郊外・探索マップにも近接マスに表示。マップでは足元のミント色の目印で区別する。
挑戦券の発行条件や確率、敵・既存装備の数値は変更していません。2人時の難易度は今後の実機調整対象です。
